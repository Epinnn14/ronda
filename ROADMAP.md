# Roadmap

## Next
- [ ] **Pengumuman** (announcements) with an optional WhatsApp broadcast text.
- [ ] **Bukti bayar** — upload a transfer screenshot per payment; residents can self-report, pengurus confirms.
- [ ] **QRIS / transfer reference** field and monthly reconciliation view.
- [ ] Print-friendly A4 roster for the pos ronda wall (one page per month).
- [ ] Attendance for ronda (hadir / izin / diganti) and fines (*denda*) that flow into the cash book.

## Later
- [ ] Multiple RTs under one RW with an RW-level summary.
- [ ] Residents (anggota keluarga) with KTP-free minimal data, for surat pengantar requests.
- [ ] Export cash book to PDF/XLSX for the yearly *pertanggungjawaban*.
- [ ] PostgreSQL + Docker Compose deployment guide.
- [ ] i18n (English UI) using Django's translation framework.
